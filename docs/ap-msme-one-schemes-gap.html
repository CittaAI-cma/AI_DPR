Source: live catalog at https://apmsmeone.ap.gov.in/schemes (31 entries in portal JS bundle)  ·  App catalog: client/src/lib/ventureMatch/schemes.ts  ·  Date: 18 Sep 2026  ·  Rev 2 — official errata applied (SCLCSS, PMEGP_2ND, Stand-Up caution, conditional questions)

Official execution contract (errata): Build against this checklist, not the original Rev 1 CLCSS proposal.

  • CLCSS rename: Replace generic CLCSS with SCLCSS (SC/ST-owned MSEs only, 25% up to ₹25 Lakh). Route general-category tech upgrade to existing AP_TECH_UPGRADE (20% under AP MSME-EDP 4.0).
  • PMEGP_2ND: Require stage = brownfield (or restart) + upgradeIntent = secondPmegpLoan; hard-fail on greenfield.
  • Non-DPR CTAs: CHAMPIONS, ESDP, ATI, NTCEC — no 18-step P&L.
  • Cluster routing: MSECDP, SFURTI, APCDP, APICF → /cluster-dpr/create.
  • Question gating: Show upgradeIntent, qualityGoal, sectorFlag, procurementInterest only when prior answers unlock them.

Decision for Create New Latest DPR: do not add cluster / common-facility schemes to the individual scheme-card picker. Route those users to Cluster DPR. Integrate the remaining missing unit-level schemes into Scheme Finder scoring and into Create New Latest DPR overlays (full 18-step bank DPR, short overlay, or no-DPR redirect).

1. How the 31 were counted

The public SPA at /schemes loads a schemes module. That module contains exactly 31 scheme objects with id, name, shortName, and category. Category cluster is used for CFC / industrial-estate / traditional-cluster programmes.

This document treats that 31 as the portal’s official list. Confirm live GOs, ceilings, and agency names before locking a DPR.

3. Cluster schemes — 4, do not put on Create New Latest DPR cards

These are multi-unit / SPV / Common Facility Centre programmes. Create New Latest DPR is a single-unit report. Forcing a proprietor through CFC, shareholding, and cluster employment grids produces a document a scheme officer will reject.

PortalWhy clusterWhere it belongs in this app
MSE-CDP
MSECDP		 GoI grant for CFCs (indicative up to ₹15–30 Cr) and industrial-estate infrastructure. Needs many units + SPV. Cluster DPR /cluster-dpr/create. Optional Scheme Finder result: “Use Cluster DPR”, not individual cards.
SFURTI Regeneration of traditional industries as clusters (CFC, raw-material bank, design). IA + SPV model. Cluster DPR. Matcher: activity craft + many artisans → cluster CTA.
APCDP State cluster development programme (same shape as MSE-CDP / SFURTI). Cluster DPR. AP domicile boost. Do not overlay on individual 18 steps.
APICF Pharma common facilities (testing, ETP, logistics) per cluster, not one factory’s plant. Cluster DPR with pharma extras. Individual pharma units use PTUAS / PMPDS instead.

Product rule: the Create New Latest DPR picker must not list these four. If Scheme Finder ranks them, show a card that navigates to Cluster DPR with a short explanation (“this is a multi-unit / CFC scheme”).

6. Current Create New Latest DPR overlay — baseline

Shared skeleton: steps 1–18. Overlay via matchedSchemeCode in schemeFormConfig.ts:

  • Hidden steps: Vishwakarma and SVANidhi drop 15, 16, 17.
  • Step 1 extras: craft/tools (Vishwakarma), CoV/UPI (SVANidhi), FSSAI (PMFME), APIIC park (AP EDP).
  • Step 12/15: MUDRA Shishu–Kishore hides land/building; Nayak WC on step 15.
  • Step 18 uploads: scheme-specific lists; default Aadhaar/PAN, Udyam, passbook, quotations.
  • Most of the 9 mapped portal schemes other than PMEGP / MUDRA / Vishwakarma / PMFME still use the generic “no extra fields on 1–17” impact copy.

7. Shared questions to add once (conditional — not all at once)

Add a small number of Scheme Finder questions so the missing schemes can be scored without a 40-question wizard. Strict gating prevents questionnaire fatigue:

New question IDWhen shownOptions (summary)Unlocks
supportType Always (after stage) loanOrSubsidy, guarantee, certification, training, marketingFair, clusterCfc, notSure Filters ESDP/ZED/LEAN/PMS vs bank DPR vs Cluster DPR.
upgradeIntent Only if stage = brownfield or restart expandSameLine, techUpgrade, secondPmegpLoan, workingCapitalOnly, notSure 2nd PMEGP, SCLCSS, ECLGS, PTUAS, AP tech upgrade.
qualityGoal Only if supportType = certification zed, lean, ipr, none, notSure ZED, LEAN, IPR.
sectorFlag Only if activity = mfg, craft, or food none, pharma, coir, handloom, notSure PTUAS, PMPDS, CVY, NHDP.
procurementInterest Only if owner includes sc or st yes, no, notSure National SC/ST Hub vs ordinary credit.

Handoff to Create New Latest DPR must pass these new fields in ventureMatchAnswers so overlays and uploads can branch. Clear skipped answers when the user goes back and changes a gating answer.

8. Missing schemes — how Scheme Finder and Create New Latest DPR change

Each card below is the integration spec. Codes in backticks are proposed app codes.

8.1 Credit / loan overlays (keep full or near-full DPR)

2nd Loan (PMEGP) — proposed PMEGP_2ND

Missing Portal: upgrade loan for existing PMEGP / REGP / MUDRA units (indicative subsidy on upgrade cost).

Scheme Finder

  • Require stage = brownfield (or restart with prior unit).
  • Require upgradeIntent = secondPmegpLoan.
  • Hard-fail if stage = greenfield or idea (that is first PMEGP only).
  • Prefer priorSubsidy = repaid (existing assisted unit fully repaid).
  • Reuse PMEGP owner / education / rural location scoring; do not double-count as a new unit.

Create New Latest DPR

  • Keep 18 steps but retitle copy: “upgrade of existing unit”, not “establishment of new unit”.
  • Step 1 extras: previous scheme (PMEGP / REGP / MUDRA), previous sanction amount, year of first subsidy, Udyam of existing unit.
  • Step 9–12: only incremental machinery / civil — not a greenfield land story.
  • Step 18: prior sanction letter, subsidy claim / adjustment proof, CA certificate of existing investment, quotations for new P&M.
  • Brief pack: separate from first PMEGP (eligibility is existing assisted unit).

ECLGS — proposed ECLGS

Emergency / additional working-capital guarantee for existing MSMEs. Not a greenfield project loan.

Scheme Finder

  • Require existing unit: stage brownfield; udyam yes or applied.
  • upgradeIntent = workingCapitalOnly (or supportType = guarantee).
  • Fail idea / greenfield with no operations.

Create New Latest DPR

  • Do not pretend this is a 18-step capex DPR. Use a short WC pack: unit identity, last 12 months turnover, existing limits, additional WC sought, repayment, bank statements.
  • Hide or collapse steps 9–10, 16 (implementation Gantt) and cluster-style impact.
  • Step 18: Udyam, GST returns / ITR, bank statements, existing sanction, CA turnover certificate.
  • If product insists on one form: keep steps 1, 4, 11, 13, 14, 18 visible only.

SCLCSS (not general CLCSS) — proposed SCLCSS

Policy: General CLCSS / TUS closed permanently on 31 March 2020. The only active central credit-linked capital subsidy for technology upgradation is SCLCSS — strictly for SC/ST-owned MSEs, indicative 25% capital subsidy up to ₹25 Lakh. Do not implement a generic CLCSS code.

General-category brownfield tech upgrade → existing state scheme AP_TECH_UPGRADE (20%).

Scheme Finder

  • stage brownfield or restart; upgradeIntent = techUpgrade.
  • owner includes sc or st (hard requirement).
  • activity mfg / food / craft (not pure vending).
  • Budget typically machinery-sized — fail under2L unless quotes exist.
  • If owner is general / not SC-ST and wants tech upgrade → match AP_TECH_UPGRADE instead (when AP domicile rules pass).

Create New Latest DPR

  • Full 18-step bank DPR is appropriate (term loan + capital subsidy).
  • Step 1 extras: existing vs proposed technology, SC/ST ownership proof reminder.
  • Step 12: plant & machinery dominant; land/building optional.
  • Step 13: term loan + SCLCSS subsidy line + promoter margin.
  • Step 18: caste certificate, machinery quotations with tech specs, existing Udyam, term-loan sanction (or in-principle), CA certificate of existing FCI.
  • Share overlay patterns with existing AP_TECH_UPGRADE where possible.

8.2 Certification / quality — short overlay, not 18 bank steps

ZED — proposed ZED

Scheme Finder: supportType = certification or qualityGoal = zed; existing unit preferred; Udyam yes/willing.

Create New Latest DPR: do not run full bank DPR. Visible steps: 1 (unit), 4 (profile), 11 (applicant), plus a new compact block “ZED assessment” (current level, target Bronze/Silver/Gold, consultant, assessment fee). Step 18: Udyam, existing QMS if any. Generate a certification assistance note, not a term-loan DPR. CTA from matcher: “Prepare ZED pack” not “Generate bank DPR”.

LEAN — proposed LEAN

Scheme Finder: qualityGoal = lean; brownfield manufacturing / food.

Create New Latest DPR: short pack: process map, bottleneck, consultant, implementation cost. Hide 5-year P&L unless they also pick a credit scheme. Step 18: Udyam, shop-floor photos optional.

IPR (MSME Innovative) — proposed MSME_IPR

Scheme Finder: qualityGoal = ipr, or supportType = certification with innovation intent. Knowledge / mfg / food.

Create New Latest DPR: extras: IP type (patent / design / trademark / GI), filing stage, attorney cost. Hide capex tables. Step 18: draft specification or TM search, Udyam.

MSME Champions — proposed CHAMPIONS

Scheme Finder: low weight; supportType not loan. This is a helpdesk / delayed-payment / public-procurement facilitation channel.

Create New Latest DPR: no 18-step form. Result card: “Raise on Champions / contact DIC” plus optional 5-field complaint template. Do not add to scheme picker as a DPR overlay.

8.3 Skills / institutions — usually no DPR

ESDP — proposed ESDP

Scheme Finder: supportType = training; idea / greenfield welcome; age/education already captured.

Create New Latest DPR: skip. After match, CTA = “Register interest for ESDP batch” (name, district, trade). Optionally prefill Create New Latest DPR vanilla if they later want a bank DPR.

ATI — proposed ATI

Assistance is to training institutions / EDIs, not a citizen unit. Do not add to individual picker. Scheme Finder: hide unless a future “I represent an institution” path exists.

National SC/ST Hub — proposed SCST_HUB

Scheme Finder: owner includes sc or st; procurementInterest = yes; Udyam yes/willing.

Create New Latest DPR: procurement-readiness pack (not term loan): products, GeM/tender experience, capacity, quality certs. Step 18: caste certificate, Udyam, cancelled cheque. Keep 18-step bank DPR only if they also match PMEGP/MUDRA/Stand-Up.

NTCEC (Technology Centres) — proposed NTCEC

Scheme Finder: supportType = training or techUpgrade; mfg.

Create New Latest DPR: service request (tooling / training / job work), not a loan DPR. CTA: nearest MSME Technology Centre / extension centre.

8.4 Innovation / green

ASPIRE — proposed ASPIRE

Scheme Finder: rural location or agri-allied / livelihood; idea or greenfield; innovation / incubator intent. Fail large above10Cr factory budgets.

Create New Latest DPR: livelihood / incubation DPR: shorter financials (maybe hide 15–17 like Vishwakarma). Step 1 extras: livelihood activity, incubator name if any. Step 18: rural address proof, concept note.

MSE-GIFT — proposed MSE_GIFT

Scheme Finder: brownfield mfg/food; upgradeIntent = techUpgrade; optional “green machinery” chip.

Create New Latest DPR: same skeleton as SCLCSS / AP tech upgrade but extras: energy baseline (kWh), old vs new machine, expected saving. Step 18: energy bill, quotations for EE equipment, Udyam. Can sit beside MSE_SPICE.

8.5 Market and sector-specific

PMS (Procurement & Marketing Support) — proposed PMS

Scheme Finder: supportType = marketingFair; Udyam yes; existing unit preferred.

Create New Latest DPR: marketing annex: event name, city class, stall size, space-rent estimate — not plant DPR. Hide steps 12–17 or replace with a 4-field fair budget. Step 18: Udyam, previous fair photos optional. If they also need a term loan, keep a second CTA to vanilla/PMEGP DPR.

Coir Vikas Yojana — proposed CVY

Scheme Finder: sectorFlag = coir, or activity = craft/mfg + coir products. AP coastal districts boost later if needed.

Create New Latest DPR: 18-step bank/subsidy DPR. Step 1 extras: coir product line, Coir Board registration planned/yes. Step 18: Coir Board docs, quotations. Brief pack from Coir Board guidelines (confirm live).

NHDP (Handloom) — proposed NHDP

Scheme Finder: sectorFlag = handloom; activity = craft; may combine with Vishwakarma (different benefit — do not auto-merge).

Create New Latest DPR: extras: loom type, weaver ID / handloom corp membership, yarn. May drop heavy P&L like Vishwakarma if it is a weaver household, not a mill. Step 18: weaver ID, Aadhaar, passbook.

PTUAS — proposed PTUAS

Scheme Finder: sectorFlag = pharma; brownfield; techUpgrade.

Create New Latest DPR: 18-step upgrade DPR. Extras: WHO-GMP / Schedule M status, product licences. Step 18: manufacturing licence, pollution consent, quotations, CA FCI. Distinct from APICF (cluster common facilities).

PMPDS — proposed PMPDS

Scheme Finder: sectorFlag = pharma; can be promotion / bulk-drug park / medical devices — score separately from PTUAS.

Create New Latest DPR: extras: device vs formulation, CDSCO / SLA licences. Uploads: product licence, Udyam, quotations. Use full DPR if capex; short pack if only promotional support.

10. Recommended implementation order

  1. Guardrails: keep 4 cluster schemes off the individual picker; add Cluster DPR CTAs in Scheme Finder for MSE-CDP / SFURTI / APCDP / APICF.
  2. Matcher questions: add supportType always; gate upgradeIntent / qualityGoal / sectorFlag / procurementInterest (unblocks 2nd PMEGP, SCLCSS, ECLGS, ZED/LEAN filter).
  3. Highest-value DPR overlays: PMEGP_2ND, SCLCSS (SC/ST only; general → AP_TECH_UPGRADE), MSE_GIFT.
  4. Short packs: ZED, LEAN, PMS, ECLGS (stop sending these users through 18 empty bank steps).
  5. Sector extras: CVY, NHDP, PTUAS / PMPDS.
  6. Non-DPR CTAs: ESDP, Champions, NTCEC; hide ATI from citizen matcher.
  7. For each new code: SchemeRule in schemes.ts, brief in schemeBriefs/*, extras/uploads/hidden steps in schemeFormConfig.ts, picker card (if DPR shape allows), and updates to both business-logic markdown files.

10a. Policy pitfalls (do not regress)

  • Do not revive general CLCSS as an app code.
  • Do not allow PMEGP_2ND on greenfield / idea stage.
  • Do not quote unverified Stand-Up India ceilings after the original window ended (Mar 2025) until new guidelines are published.
  • Do not force ZED / LEAN / IPR / PMS / ESDP / Champions / NTCEC through a full bank P&L.

12. What this document is not

  • Not a substitute for live scheme GOs. Ceilings on the portal (e.g. older PMEGP ₹25L/₹10L vs current KVIC ₹50L/₹20L) already diverge — briefs must say “confirm with DIC / agency”.
  • Not an instruction to add all 18 as full 18-step bank DPRs. Training, certification, and fair-support schemes would harm users if forced through plant-and-machinery tables.
  • Not a Cluster DPR redesign. MSE-CDP already matches the existing cluster form (SPV, CFC, member units).
