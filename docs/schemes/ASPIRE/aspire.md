# ASPIRE — DPR format & form questions

> Scheme code: `ASPIRE`  
> Source of truth for Create New Latest DPR.  
> Derived from ASPIRE (A Scheme for Promotion of Innovation, Rural Industries and Entrepreneurship) — MoMSME.

**Related app files:** `ASPIRE_STEPS`, `aspireQuestions.ts`, `schemeFormConfig.ts`, `IndividualDPRForm.tsx`

---

## 1. Why this format

ASPIRE supports **rural innovation / livelihood incubators (LBI)** and related entrepreneurship — lighter financials than a ₹1 Cr+ factory term loan.

Create New Latest DPR uses its **own 10 consecutive steps**.

---

## 4. Form questions (10 steps)

1. Cover & incubator (`incubatorName`, `innovationBrief`)  
2. Activity story  
3. Location  
4. Unit / livelihood profile  
5. Market  
6. Premises  
7. Applicant  
8. Light project cost  
9. Means of finance  
10. Uploads: rural address, concept note, Udyam if ready  

Update this file + `aspireQuestions.ts` + `ASPIRE_STEPS` together.
