# MSME Sustainable ZED Certification — DPR format & form questions

> Scheme code: `ZED`  
> Source of truth for Create New Latest DPR when this scheme is selected.  
> Derived from MSME Sustainable ZED Certification Scheme (MoMSME) — portal zed.msme.gov.in.

**Related app files:** `schemeStepCatalog.ts` (`ZED_STEPS`), `zedQuestions.ts`, `schemeFormConfig.ts`, `IndividualDPRForm.tsx`

---

## 1. Why this format

ZED is a **quality / sustainability certification** pathway for MSEs (Bronze / Silver / Gold) — **not** a bank term loan or plant FCI DPR.

Create New Latest DPR uses its **own 5 consecutive steps**.

## 3. Product rules (quick)

| Rule | Value |
|------|--------|
| Who | Udyam-registered (or willing) MSE |
| Levels | Bronze → Silver → Gold |
| Pack | Certification assistance note — no 5-year P&L |

---

## 4. Form questions (5 steps)

1. Cover & ZED levels (`zedCurrentLevel`, `zedTargetLevel`)  
2. Unit profile  
3. Market / quality need  
4. Applicant  
5. Uploads: Udyam, Aadhaar/PAN  

Update this file + `zedQuestions.ts` + `ZED_STEPS` together.
