# Procurement and Marketing Scheme (PMS) — DPR format & form questions

> Scheme code: `PMS`  
> Source of truth for Create New Latest DPR.  
> Derived from MoMSME Procurement & Marketing Support / trade-fair assistance guidelines.

**Related app files:** `PMS_STEPS`, `pmsQuestions.ts`, `schemeFormConfig.ts`, `IndividualDPRForm.tsx`

---

## 1. Why this format

PMS is a **marketing / trade-fair annex** — stall / participation support — **not** a plant DPR. Use a separate term-loan DPR if needed.

Create New Latest DPR uses its **own 5 consecutive steps**.

## 4. Form questions (5 steps)

1. Cover & fair (`eventName`, `stallSize`, `estimatedFairCost`)  
2. Unit profile  
3. Market / offtake from fair  
4. Applicant  
5. Uploads: Udyam (+ previous fair photos optional)
