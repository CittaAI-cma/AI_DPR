# PMPDS — DPR format & form questions

> Scheme code: `PMPDS`  
> Pharmaceutical & Medical Devices Promotion and Development Scheme — promotion / development note.

**Related app files:** `PMPDS_STEPS`, `pmpdsQuestions.ts`, `schemeFormConfig.ts`, `IndividualDPRForm.tsx`

---

## 1. Why this format

Often a **promotion / development** support note — not a full plant DPR. Use a bank pack separately if term-loan capex is also needed.

Create New Latest DPR uses its **own 5 consecutive steps**.

---

## 2. Reference

Confirm live DoP PMPDS guidelines for eligible activities and ceilings.

---

## 3. Form questions (5 steps)

1. Cover (`deviceOrFormulation`, `entrepreneurName`, `promotionNeed`)  
2. Unit / product profile  
3. Market / need  
4. Applicant  
5. Uploads: manufacturing / product licence if available, Udyam  

Update this file + `pmpdsQuestions.ts` + `PMPDS_STEPS` together.
