# National SC/ST Hub — DPR format & form questions

> Scheme code: `SCST_HUB`  
> Source of truth for Create New Latest DPR.  
> Derived from National SC/ST Hub (NSSHO / MoMSME) procurement-readiness programmes.

**Related app files:** `SCST_HUB_STEPS`, `scstHubQuestions.ts`, `schemeFormConfig.ts`, `IndividualDPRForm.tsx`

---

## 1. Why this format

SC/ST Hub is **procurement readiness / market access** for SC/ST MSEs — **not** a term loan by itself (distinct from `SCLCSS` capital subsidy).

Create New Latest DPR uses its **own 5 consecutive steps**.

## 4. Form questions (5 steps)

1. Cover & eligibility (`sclcssCategory` SC/ST, `gemExperience`)  
2. Unit profile  
3. Market / procurement focus  
4. Applicant  
5. Uploads: Caste certificate, Udyam, cancelled cheque  

Update this file + `scstHubQuestions.ts` + `SCST_HUB_STEPS` together.
