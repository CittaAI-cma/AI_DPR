# National Handloom Development Programme — DPR format & form questions

> Scheme code: `NHDP`  
> Source of truth for Create New Latest DPR.  
> Derived from National Handloom Development Programme (Ministry of Textiles) weaver / handloom support guidelines.

**Related app files:** `NHDP_STEPS`, `nhdpQuestions.ts`, `schemeFormConfig.ts`, `IndividualDPRForm.tsx`

---

## 1. Why this format

NHDP is a **weaver / handloom** overlay — loom, yarn, product line — lighter than a factory FCI DPR (similar weight to Vishwakarma artisan packs).

Create New Latest DPR uses its **own 10 consecutive steps**.

## 4. Form questions (10 steps)

1. Cover & loom (`loomType`, `weaverId`)  
2. Trade / process  
3. Location  
4. Weaver profile  
5. Market  
6. Workplace  
7. Applicant  
8. Tools / WC cost  
9. Means of finance  
10. Uploads: Weaver ID, Aadhaar, passbook  

Update this file + `nhdpQuestions.ts` + `NHDP_STEPS` together.
